# Подключение общей ленты через Supabase

Сайт работает на GitHub Pages и не хранит серверные секреты. Для общей ленты используется только публичный ключ Supabase с RLS.

1. Создай проект Supabase в своём аккаунте.
2. В Dashboard → SQL Editor выполни `supabase/schema.sql` из этого каталога.
3. Возьми Project URL и publishable key (или legacy anon key) в Project Settings → API Keys.
4. Передай сюда **только** Project URL и publishable/anon key, чтобы подключить их к сайту.

Не присылай `service_role` / secret key: он обходит политики безопасности и не должен находиться в браузере или публичном GitHub-репозитории.

Сейчас вставлять гайды могут все посетители без входа, а читать могут все. RLS ограничивает поля и URL Steam; редактирование и удаление через сайт запрещены. Для открытой формы позже желательно добавить вход через Steam/почту и модерацию от спама.
